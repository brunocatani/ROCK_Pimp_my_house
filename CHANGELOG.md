# Changelog

## 1.0.0

First release. Decoration used to live inside ROCK 0.92; it is now this
optional addon for ROCK 1.0.0.

- Hold a loose object against a fixed surface and click the stick of the hand
  holding it: the object stays exactly there, and keeps its place through saves,
  reloads and cell changes. Grab or pull it normally to take it again.
- Each hand's stick click places that hand's object, and an object held in both
  hands answers either click. The other hand's click keeps its own actions
  (Favorites menu, RobCo PALM).
- Weapons, held or equipped, are placed with a one-second hold of the stick
  click, so a short click still works ROCK's bipod.
- Needs ROCK 1.0.0. Without ROCK the addon stays off; a ROCK without the API it
  was built for stops the game at the main menu with an error box naming the
  mismatch. No settings: installing the plugin turns the feature on.
